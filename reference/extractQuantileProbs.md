# Extract Quantile Props

Extract lower and upper probabilities for the
[`stats::quantile`](https://rdrr.io/r/stats/quantile.html) function

## Usage

``` r
extractQuantileProbs(prop = 0.8)
```

## Arguments

- prop:

  (numeric) double between 0 and 1: length of credibility interval. The
  default value is 80 percent.
