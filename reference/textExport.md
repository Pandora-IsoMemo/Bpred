# Text Export Button UI

Text Export Button UI

Text Export Server

## Usage

``` r
textExportButton(id, title = "Download")

textExport(input, output, session, printFun, filename = "output")
```

## Arguments

- id:

  namespace id

- title:

  title of tab in tabset panel

- input:

  shiny input object

- output:

  shiny output object

- session:

  shiny session

- printFun:

  print function

- filename:

  (character) file name
