# Enrich Form

Enrich Form

## Usage

``` r
enrichForm(formDF, parNames, formulasObject, y)
```

## Arguments

- formDF:

  (data.frame) a dataframe containing the form, name, x and y variables

- parNames:

  (character) names of parameters from form

- formulasObject:

  (list) fitted formulas object

- y:

  (numeric) y variable
